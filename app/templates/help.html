1. Vos identifiants Windows

L'Agora est relié à l'annuaire de l'institut : vous n'avez aucun compte à créer.

  • Identifiant : le même que pour ouvrir votre session Windows, au format nprenom.
  • Mot de passe : votre mot de passe Windows. Si vous le changez, L'Agora le prend en compte immédiatement.
{{ fig('login.png', "Écran de connexion à L'Agora") }}

2. Avec votre compte Microsoft 365

Sous le bouton Connexion, « Connexion avec mon compte Microsoft 365 » vous connecte sans saisir de mot de passe si votre poste est déjà connecté à Microsoft 365. Le bouton « Accès à l'intranet » du site SharePoint de l'institut fait de même.

3. Sur mobile et tablette

L'adresse est la même, depuis le réseau de l'institut. Le menu se trouve derrière le bouton ☰ en haut à gauche et les pages s'adaptent à la largeur de l'écran.

{{ tip('Problème de connexion ?', "Si votre mot de passe fonctionne sur Windows mais pas sur L'Agora, votre compte est peut-être verrouillé : contactez le Service Informatique.") }} {{ modal_close() }} {{ modal_open('modal-portail', 'bg-purple-600', 'fa-desktop', "Découverte de L'Agora") }}

1. Le portail

Dès votre connexion, vous arrivez sur le portail. De haut en bas :

  • Annonces : les informations importantes diffusées par la Communication ou la DSI.
  • Mes demandes en cours : vos demandes non terminées, avec leur statut en clair. Un clic ouvre le détail.
  • Les cartes de demande : une carte par type de besoin (Informatique, DRH, DAF, Services techniques, Imago…). Certaines cartes sont réservées aux managers et directeurs et portent une étiquette.
  • Mes dernières demandes : le récapitulatif, avec le lien vers l'historique complet.
{{ fig('portail.png', "Le portail : annonces, demandes en cours et cartes de demande") }}

2. Le menu latéral

À gauche, le menu donne accès au Portail, à l'Aide / Tuto, à Mon profil et, selon votre rôle, au Dashboard (solvers), à la Validation (managers et directeurs), aux Annonces, aux Statistiques et à l'Administration.

Le bouton en bas du menu le replie pour ne garder que les icônes et gagner de la place. Pour le rouvrir, cliquez n'importe où sur la barre d'icônes. Ce choix est mémorisé sur votre navigateur.

{{ fig('menu-replie.png', "Le menu replié : seules les icônes restent visibles") }}

3. La recherche

En haut de l'écran, la zone Rechercher… retrouve une demande par son numéro, son titre ou un mot de sa description, en tapant quelques lettres. Les résultats s'affichent au fur et à mesure.

{{ fig('recherche.png', "La recherche globale, depuis n'importe quelle page") }}

4. Les notifications

La cloche en haut à droite vous prévient quand :

  • le service a répondu dans le fil de votre demande ;
  • votre demande a été validée, refusée ou prise en charge ;
  • un rendez-vous vous est proposé ou votre demande est terminée.

Les mêmes événements vous parviennent par e-mail, selon le réglage choisi dans Mon profil.

{{ fig('notifications.png', "Le volet des notifications") }} {{ modal_close() }} {{ modal_open('modal-ticket', 'bg-green-600', 'fa-plus-circle', 'Créer une demande') }}

1. Choisir la bonne carte

Informatique : panne PC, écran, imprimante, réseau, logiciel, accès.
DRH : documents administratifs, coordonnées, rendez-vous RH.
DAF / Achats : bon de commande avec devis (voir le tuto DAF).
Services techniques : travaux, plomberie, maintenance des locaux.
Services généraux : enlèvement de matériel ou d'encombrants.
Dépannage Imago : blocage, erreur ou mot de passe du logiciel métier.
Managers et directeurs : Bon de commande en délégation, Demande Matériel, Agent recruté (FCPI), Dossier de séjour, Publication d'actualités.

2. Remplir le formulaire

En haut du formulaire, l'encadré « Avant d'envoyer — avez-vous essayé… » propose des solutions rapides (redémarrer le poste, compte verrouillé…) : votre problème peut se régler sans attendre. Le volet « Faire cette demande au nom de quelqu'un d'autre » permet de déposer pour un collègue, qui sera alors le demandeur.

  • Titre : une phrase qui résume le besoin (ex : « Écran qui ne s'allume plus »).
  • Description : ce qui se passe, depuis quand, ce que vous avez déjà essayé.
  • Service / Bureau : où vous trouver (bâtiment, étage, bureau).
  • Téléphone de contact : pour être joint rapidement.
  • Pièces jointes : glissez vos fichiers dans la zone prévue ou cliquez pour les choisir (20 Mo maximum par envoi). Une capture d'écran du message d'erreur fait gagner beaucoup de temps.
{{ fig('formulaire.png', "Le formulaire de demande Informatique") }} {{ tip('Brouillon automatique', "Ce que vous tapez est mémorisé sur votre navigateur. Si vous quittez la page avant d'envoyer, L'Agora vous proposera de reprendre votre brouillon à votre retour.", 'green') }}

3. Vérifier puis envoyer

Sous les champs, le parcours indique par où passera votre demande (validation éventuelle, service destinataire). Au clic sur Soumettre, un récapitulatif reprend tout ce que vous avez saisi : Modifier pour corriger, Confirmer la création pour envoyer. La demande reçoit alors un numéro et vous recevez une confirmation.

{{ fig('formulaire-recap.png', "Le récapitulatif avant envoi") }}

4. « Demande déjà en cours ? »

Si une de vos demandes des 30 derniers jours ressemble beaucoup à celle que vous envoyez et qu'elle est encore ouverte, L'Agora vous le signale avant l'envoi. Voir ma demande en cours ouvre la demande existante pour y ajouter un message ; Créer quand même confirme qu'il s'agit d'une nouvelle demande. Rien n'est fusionné sans vous : le service est simplement informé d'un doublon possible.

{{ fig('doublon.png', "L'alerte de doublon possible avant l'envoi") }} {{ modal_close() }} {{ modal_open('modal-status', 'bg-pink-600', 'fa-route', 'Guide des statuts') }}

Chaque demande affiche une frise de suivi, comme le suivi d'un colis : l'étape en cours est mise en avant, les étapes passées sont cochées. Le statut est aussi écrit en clair au-dessus.

{{ fig('frise.png', "La frise de suivi d'une demande en cours de traitement") }}

1. Retrouver ses demandes

Le portail affiche vos demandes en cours. Le menu Historique (lien « Tout voir ») liste toutes vos demandes, avec des filtres par statut et période et un export CSV ou Excel. Cliquez sur une ligne pour ouvrir le détail.

{{ fig('historique.png', "L'historique de mes demandes, avec filtres et export") }}

2. Le détail d'une demande

En haut, la frise de suivi et le statut en clair ; puis les informations saisies, les pièces jointes et le nom du solver qui s'en occupe ; en bas, le fil de discussion.

{{ fig('detail-ticket.png', "Le détail d'une demande en cours") }}

3. Discuter avec le service

Le fil de discussion sert à répondre aux questions du service (« Pouvez-vous me donner le message d'erreur ? ») et à ajouter des précisions ou des fichiers. Chaque message déclenche une notification de l'autre côté.

{{ fig('discussion.png', "Le fil de discussion, vu par le service : les notes internes en jaune ne sont jamais visibles du demandeur") }}

4. Modifier ma demande

Tant que la demande n'est ni terminée ni refusée, le bouton « Modifier ma demande » permet de corriger le titre, la description, le lieu, le téléphone, les lignes d'un bon de commande et d'ajouter des pièces jointes. Les changements sont ajoutés au fil de la demande et la personne qui la traite est prévenue.

{{ fig('modifier-formulaire.png', "Le formulaire de modification d'une demande") }}

5. Rendez-vous

Quand une intervention sur place est nécessaire, le service peut vous proposer un rendez-vous. Depuis le détail, vous l'acceptez, le refusez ou transmettez jusqu'à trois créneaux qui vous conviennent. Un rappel vous est envoyé le jour même à 9 h.

{{ fig('rdv.png', "Une proposition de rendez-vous à accepter, refuser ou renégocier") }}

6. À la fin : votre avis

Une fois la demande terminée, un clic suffit pour donner votre avis : Satisfait, Moyen ou Insatisfait, avec un commentaire facultatif. Cet avis est réservé aux managers et directeurs. Si le problème revient dans les 7 jours, l'encadré « Ce n'est pas résolu ? » permet d'expliquer ce qui ne va pas et de rouvrir la demande sans en créer une nouvelle.

{{ fig('avis.png', "Donner son avis ou rouvrir une demande terminée") }} {{ modal_close() }} {{ modal_open('modal-profil', 'bg-sky-600', 'fa-palette', "Mon profil et l'affichage") }}

Le menu Mon profil regroupe trois onglets.

1. Compte

Vos coordonnées (téléphone, bureau), vos initiales ou votre photo, et le réglage des e-mails que vous souhaitez recevoir : tout, seulement l'essentiel, ou rien (les notifications restent visibles dans L'Agora).

2. Apparence

  • Mode d'affichage : clair, sombre ou automatique (suit Windows).
  • Couleur d'accent : la couleur des boutons et des liens.
  • Style visuel : « Plat » par défaut (cartes opaques, coins nets), ou un des autres styles proposés, comme « Liquid Glass » (verre dépoli, toujours en sombre) ou « Bento ».
  • Taille du texte, densité et contraste élevé : pour le confort de lecture.

Chaque réglage s'applique et s'enregistre immédiatement, sans bouton à valider, et vous suit sur tous vos postes. Le bouton soleil/lune de l'en-tête bascule rapidement entre clair et sombre.

{{ fig('profil-apparence.png', "L'onglet Apparence de Mon profil") }}

3. Signaler un bug

Un problème dans L'Agora lui-même (page qui ne s'affiche pas, bouton sans effet) ? Décrivez-le ici : une demande Informatique est créée directement avec les informations techniques utiles.

{{ modal_close() }} {{ modal_open('modal-daf-standard', 'bg-orange-600', 'fa-file-invoice', 'DAF : bon de commande') }} {{ tip('Important', "Un bon de commande suit un circuit de validation complet (manager, DAF, direction) : prévoyez le délai nécessaire. Les bons DAF se valident toujours un par un.", 'orange') }}

1. Saisir la demande

Depuis la carte DAF / Achats du portail, renseignez :

  • Pour quel service : si vous gérez plusieurs services, choisissez celui pour lequel vous commandez.
  • Infos commande : l'UF (unité fonctionnelle, le service qui porte la dépense, choisie parmi tous les services de l'institut), le budget (investissement ou fonctionnement) et le lieu de livraison.
  • Le fournisseur : s'il est déjà référencé, son nom et son e-mail suffisent. Pour un nouveau fournisseur, ajoutez son SIRET, son téléphone et son RIB.
  • Les lignes de commande : désignation, référence, quantité et prix unitaire ; « Ajouter une ligne » pour en créer d'autres. Le total se calcule tout seul. Indiquez si les prix sont HT ou TTC.
{{ fig('daf-formulaire.png', "Infos commande (UF, budget, livraison) et fournisseur") }} {{ fig('daf-lignes.png', "Les lignes de commande, le type de prix et la zone du devis") }}

2. Joindre le devis

Le devis du fournisseur, en PDF, est obligatoire : un bon de commande sans devis sera renvoyé. Glissez-le dans la zone « Devis (PDF) ». Si vous l'avez oublié, ajoutez-le ensuite via « Modifier ma demande ».

3. Le circuit de validation

  1. Validation manager : votre responsable hiérarchique valide ou refuse (un directeur qui commande saute cette étape).
  2. Préparation par la DAF : un agent DAF prend la demande, vérifie et prépare le bon de commande.
  3. Validation du manager DAF, puis signature du directeur.
  4. Terminée : le bon signé est joint à la demande, la commande peut partir.

Le service DAF est prévenu.", 'orange') }} {{ modal_close() }} {{ modal_open('modal-daf-delegation', 'bg-yellow-500', 'fa-signature', 'DAF : délégation (< 400 €)') }} {{ tip('Procédure accélérée', "Pour les petits achats (moins de 400 € TTC, soit 380 € HT), la validation hiérarchique est sautée : la demande part directement au service DAF.", 'yellow') }}

1. Qui et comment

  • Réservée aux managers et directeurs : carte « Bon de commande : Délégation signature » sur le portail.
  • Le formulaire est identique au bon de commande standard (fournisseur, UF, lignes, devis obligatoire).
  • Si le total dépasse la limite, l'envoi est refusé avec un message : passez par le bon de commande standard.

2. Traitement direct

Dès l'envoi, la demande passe « À prendre en charge » dans la file du service DAF, qui la traite sans attendre de validation. Vous suivez son avancement comme n'importe quelle demande.

1. L'écran Validation

Le menu Validation liste les demandes qui attendent votre accord. En haut, un bandeau signale les tickets hors délai de votre service, puis quatre indicateurs : demandes à valider, demandes en attente depuis plus de 48 h, votre délai de validation et tickets hors délai.

Trois onglets séparent la validation d'équipe (N1), la validation technique ou budgétaire (N2, directeurs) et les recrutements (FCPI). Les formulaires apparaissent sous les tickets, avec un bouton « Voir & Valider ».

{{ fig('validation.png', "L'écran Validation d'un responsable") }}

2. Valider ou refuser

  • Valider : la demande part immédiatement vers le service compétent. Cochez plusieurs lignes puis « Valider la sélection » pour valider en lot (les bons de commande DAF se valident un par un).
  • Refuser : le motif est obligatoire (« Budget dépassé », « Pas prioritaire »…). Il est ajouté au fil de la demande et envoyé par e-mail au demandeur.
{{ fig('validation-refus.png', "Le refus d'une demande, avec son motif") }} {{ tip('Rappels automatiques', "Une demande qui attend trop longtemps déclenche un rappel aux validateurs, puis une alerte au directeur du service. Pendant vos absences, déléguez vos validations à un collègue : il verra et validera à votre place, avec une trace « pour le compte de ».", 'red') }}

3. Piloter une demande déjà validée

Pour toutes les demandes sauf les bons de commande DAF, le bloc Pilotage de la demande du détail vous permet, même quand la demande est déjà dans la file d'un service :

  • de la refuser avec un motif : le demandeur et le service sont prévenus ;
  • de la supprimer définitivement, messages et pièces jointes compris (irréversible, tracé dans le journal).
{{ fig('pilotage.png', "Le bloc Pilotage de la demande, réservé aux managers et directeurs") }}

4. Suivre le travail de l'équipe

Dans le Dashboard, la liste « Mes tickets en cours » affiche aussi les tickets pris en charge par les solvers de votre service, avec le nom de chacun. Vous pouvez y remettre un ticket dans le pool ou le transférer. Sur une demande terminée, l'avis du demandeur (note et commentaire) n'est visible que par les managers et directeurs.

{{ fig('dashboard-equipe.png', "Les tickets de l'équipe dans le Dashboard, avec le solver en charge") }} {{ modal_close() }} {{ modal_open('modal-fcpi', 'bg-indigo-600', 'fa-user-plus', 'Responsable : fiche de création de poste (FCPI)') }}

1. Un formulaire unique

Depuis la carte Agent recruté (FCPI) (managers et directeurs), renseignez tout ce qui concerne l'arrivée :

  • Données de l'agent : date d'entrée, UF, nom, prénom, fonction, service.
  • Données RH : statut contractuel, temps de travail, CV et fiche de poste en PDF, demande de simulation de salaire.
  • Imago : cochez si l'agent a besoin d'un compte sur le logiciel métier.
  • Informatique : matériel demandé (téléphone, PC fixe ou portable) et accès spécifiques.
  • Badge & sécurité : photo (facultative), localisation du poste, besoins en clés ou badge.
{{ fig('fcpi1.png', "La fiche FCPI : données de l'agent") }} {{ fig('fcpi2.png', "La fiche FCPI : données RH, Imago et informatique") }} {{ fig('fcpi3.png', "La fiche FCPI : badge et sécurité, puis envoi") }}

2. Le circuit

La fiche est validée par le manager RH, puis par le directeur RH. Un refus est motivé et vous revient par e-mail.

3. Les tickets générés automatiquement

Dès la validation RH, L'Agora crée un ticket par service, chacun suivi dans son propre Dashboard :

DRH : dossier administratif et contrat.
Informatique : matériel, compte et accès.
Sécurité : badge et accès physiques.
Imago : compte métier (si demandé).

Ces tickets sont liés entre eux : depuis l'un d'eux, vous voyez l'avancement des autres. Le circuit détaillé figure dans la page Circuits de validation.

{{ modal_close() }} {{ modal_open('modal-tech', 'bg-gray-700', 'fa-toolbox', 'Solvers : le Dashboard') }}

1. Vue d'ensemble

Le Dashboard est l'espace de travail des solvers. En haut : l'écran mural (affichage plein écran pour le service), le Planning des rendez-vous et les outils (historique et ajout manuel, stock et inventaire, gestion des prêts). Viennent ensuite quatre compteurs (tickets à attribuer, mes dossiers, tickets clôturés, en retard) et le graphique de répartition. Les tickets qui approchent ou dépassent le délai cible de leur catégorie portent un badge « Échéance » ou « Hors délai ».

{{ fig('dashboard.png', "Le Dashboard d'un solver") }}

2. Le pool

Toutes les demandes validées destinées à votre service arrivent dans la file d'attente (le pool), filtrable par service. Cliquez sur « Prendre en charge » : le ticket rejoint « Mes tickets en cours » et le demandeur est prévenu par notification et par e-mail.

{{ fig('pool.png', "Le pool : les demandes à prendre en charge") }}

3. Mes tickets en cours

Le menu Actions d'un ticket (ou l'Espace technique de son détail) permet de :

  • Discuter avec le demandeur dans le fil (des réponses types sont proposées), joindre des fichiers, et laisser des notes internes invisibles pour lui.
  • Proposer un rendez-vous (date fixée ou à confirmer) : le demandeur accepte, refuse ou envoie ses disponibilités ; rappel automatique à 9 h le jour J. L'onglet Planning regroupe les rendez-vous du service.
  • Remettre dans le pool un ticket que vous ne pouvez finalement pas traiter : il redevient « À prendre en charge » pour toute l'équipe, avec une trace dans le fil.
  • Transférer le ticket à un autre service s'il ne relève pas du vôtre, ou l'assigner à un collègue.
  • Lier des tickets entre eux. Quand L'Agora détecte un doublon probable, un bandeau le propose en un clic.
  • Clôturer une fois résolu : le demandeur est invité à donner son avis.
