Résultats FAQ

Mon mot de passe ne fonctionne pas
Votre mot de passe est synchronisé avec Windows. Si vous l'avez changé pour ouvrir votre session ce matin, c'est le nouveau qu'il faut utiliser. En cas de blocage, contactez le RSI (Xavier Richard).
Erreur "Catdance" ou 403 Forbidden
Cette erreur signifie que votre compte Active Directory n'a pas les droits nécessaires pour accéder à cette page (ex: un utilisateur qui tente d'accéder au menu Validation Manager).
Comment trouver le nom de mon PC (Hostname) ?
Le formulaire de ticket tente de le détecter automatiquement. Sinon, regardez l'étiquette bleue collée sur votre unité centrale ou pc portable (ex: PORTABLE-042).
Je ne reçois pas les notifications mail
Vérifiez votre dossier "Indésirables" (Spam) dans Outlook. Si le problème persiste, vérifiez que votre adresse email est correctement renseignée dans l'annuaire de l'entreprise.
Puis-je modifier un ticket après envoi ?
Non, le ticket est verrouillé pour garantir la traçabilité. Cependant, vous pouvez ajouter des informations ou des fichiers supplémentaires via la zone de Chat en bas du ticket.
Comment annuler une demande ?
Vous ne pouvez pas supprimer un ticket vous-même. Demandez l'annulation au technicien via le chat, ou demandez à votre Manager de le "Refuser" lors de la validation.
Quelle est la taille maximale des fichiers ?
La limite est fixée à 20 Mo par fichier. Si vous devez envoyer une vidéo ou un gros fichier, utilisez un lien OneDrive/Sharepoint dans la description.
Quel est le délai de réponse moyen ?
Pour un ticket bloquant (Priorité Haute), le délai est de 4h ouvrées. Pour une demande standard, comptez 24h à 48h.
C'est quoi la "Délégation" DAF ?
C'est une procédure simplifiée pour les achats inférieurs à 400€. En cochant cette case, votre demande contourne la validation hiérarchique pour être traitée plus vite par la DAF.
J'ai oublié de joindre le devis
Pas de panique. Ouvrez votre ticket dans l'historique et ajoutez le fichier PDF via la zone de discussion en bas de page.
Qui valide mes congés ?
L'intranet gère les demandes techniques et administratives. Pour les congés, veuillez utiliser le portail RH dédié (ex: Silae).
Comment recruter un stagiaire ?
Utilisez le formulaire FCPI (Fiche Création Poste) exactement comme pour un salarié classique. Précisez "Stagiaire" dans le type de contrat.
Je suis Manager mais je ne vois pas le menu Validation
Il vous manque probablement le groupe de sécurité GR-MANAGER dans l'Active Directory. Ouvrez un ticket support pour régulariser vos droits.
Mon collaborateur n'apparait pas dans ma liste
Cela signifie que son affectation "Service" dans l'AD est différente de la vôtre. Contactez les RH ou l'IT pour corriger l'organigramme.
L'intranet est-il accessible sur mobile ?
Oui, si votre téléphone est connecté au Wi-Fi de l'entreprise. L'interface est "responsive" et s'adapte aux petits écrans.
Le mode sombre ne reste pas activé
Le choix du thème est enregistré dans votre navigateur (LocalStorage). Si vous changez de PC ou effacez vos cookies, il se réinitialise.
Urgence vitale (Feu, Accident)
N'OUVREZ PAS DE TICKET ! Appelez immédiatement les secours (18 ou 112) et le PC Sécurité du bâtiment.
Puis-je avoir un Mac au lieu d'un PC ?
Toute demande de matériel hors catalogue standard doit être dûment justifiée dans le ticket "Demande Matériel" et est soumise à validation budgétaire stricte.
Comment exporter mes tickets ?
Il n'y a pas d'export Excel côté utilisateur pour le moment. Si vous avez besoin d'un rapport annuel, faites une demande au service IT.
Où sont stockées mes données ?
L'intranet est hébergé sur des serveurs internes sécurisés dans nos locaux (On-Premise), garantissant la confidentialité et le respect du RGPD.

Guide de Connexion

1. Identification Windows (SSO)

L'intranet ILVM est directement relié au serveur. Vous n'avez pas de compte spécifique à créer.

  • Identifiant : Utilisez votre identifiant de session Windows pnom (ex: atraore).
  • Mot de Passe : C'est le même que celui pour ouvrir votre session Windows.

Écran de connexion à l’Intranet ILVM

2. Gestion du Mot de Passe

Si vous changez votre mot de passe Windows, il est immédiatement mis à jour sur l'intranet. Inutile d'appeler le support.

Problème de connexion ?

Si votre mot de passe fonctionne sur Windows mais pas sur l'Intranet, vérifiez que votre compte n'est pas verrouillé ou contactez le Service Informatique.

Le Portail Utilisateur

1. Le Portail

Dès votre connexion, vous accédez à votre espace personnel. Il est composé de trois zones :

  • Nav Bar (Haut) : Accès rapide à l'espace Solver, Espace Validation et les notifications.
  • Zone d'Actions (Milieu) : Les cartes colorées pour créer une demande.
  • Zone de Suivi (Bas) : Le tableau "Mes dernières demandes" avec leur statut en temps réel.

Portail ILVM

2. Les Notifications

En haut à droite, l'icône vous alerte quand :

  • Un technicien a répondu à votre ticket.
  • Votre demande a été validée par votre Manager.
  • Le statut de votre ticket a changé (ex: Terminé).

Guide des Statuts

1. Tickets Standards (Support, Imago, DAF)

ATTENTE_VALIDATION

En attente du Manager (N1)

Votre demande a été envoyée mais nécessite l'approbation de votre responsable hiérarchique avant d'être traitée. (Ex: Achat DAF, Matériel).

ATTENTE_VALIDATION_N2

En attente de Direction (N2)

Validation supplémentaire requise (ex: DAF > seuil budgétaire) par un Directeur.

EN_ATTENTE

Validé / En attente de technicien

La demande est validée (ou n'avait pas besoin de validation). Elle est dans la file d'attente du service technique (Pool) et attend qu'un technicien se libère.

EN_COURS

Pris en charge

Un technicien (Solver) travaille actuellement sur votre dossier.

TERMINE

Résolu / Livré

L'intervention est finie. Le ticket est archivé.

REFUSE

Rejeté

Votre manager ou la direction a refusé la demande. Le motif du refus vous a été envoyé par email.

2. Recrutement (FCPI)

VALIDATION_RH / DRH

Validation RH

Le dossier est en cours de signature par les Ressources Humaines.

SIGNED

Signé & Actif

La fiche est validée. Les 4 tickets techniques (Info, Sécu, etc.) ont été générés automatiquement.

DAF : Délégation (< 400€)

Avantage "Fast-Track"

Pour les petits montants (inférieurs à 400€), la validation HIERARCHIQUE est contournée pour accélérer les achats courants.

1. Activer la Délégation

Dans le formulaire DAF :

  • Acceder a la carte : Bon de commande:Délégation de signature. Depuis votre portail ILVM. Accesible uniquement au responsable et Directeur.
  • Seul les montant inférieur à 400€ TTC sont autorisés.
  • Le formulaire est idendique au formulaire standard DAF.

Formulaire DAF

2. Traitement Direct

Dès que vous cliquez sur "Envoyer", le statut passe directement à EN COURS (DAF).

Votre manager n'a pas besoin de valider, mais il sera notifié pour information.

Exemple de statut DAF

Manager : Valider une demande

1. Accéder aux demandes

Dans le menu de gauche, cliquez sur "Validation Manager". Vous verrez la liste de toutes les demandes en attente provenant de vos subordonnés.

Exemple d’écran de validation manager

2. Valider ou Refuser

Pour chaque ligne, deux boutons sont disponibles :

  • Valider : Transmet immédiatement le ticket au service technique compétent.
  • Refuser : Ouvre une pop-up.

3. En cas de Refus

Vous devez saisir un motif (ex: "Budget dépassé", "Pas prioritaire"). Ce motif sera envoyé par email au collaborateur.

Exemple d’écran de refus de validation

Manager : Fiche Création de Poste

1. Le Formulaire Unique

Remplissez les informations du nouvel arrivant :

  • RH : Nom, Prénom, Date d'arrivée.
  • IT : Type de PC (Fixe/Portable), Logiciels spécifiques.
  • Sécurité : Accès parking, Badge.

Formulaire FCPI

Formulaire FCPI

2. Circuit de Validation

Une fois soumis, le dossier part chez le DRH pour signature contractuelle.

Workflow FCPI

3. Automatisation

Dès la signature DRH, l'intranet génère 4 tickets distincts :

1. Ticket Info (Préparation PC)
2. Ticket Sécurité (Badge)
3. Ticket Imago (Compte métier)
4. Ticket RH (Contrat)

Espace Technique

1. Le Pool de Tickets

Tous les tickets validés arrivent dans le "Pool". Ils sont en attente d'attribution.

Cliquez sur le bouton "Prendre en charge" pour vous l'assigner. L'utilisateur reçoit un mail : "Votre demande est prise en charge par (ex : Assane)".

Exemple d’écran de l’espace Solver

2. Vue d'ensemble & Diagramme

En haut de votre tableau de bord, vous retrouvez les compteurs clés (Total, Ouverts, Clôturés). Le Diagramme Circulaire vous donne une vision instantanée de la charge de travail actuelle (tickets en attente vs résolus).

Compteurs et de diagramme circulaire

3. Le Pool (File d'attente)

  • Consultez la liste des tickets en attente.
  • Cliquez sur le bouton "Prendre en charge" pour vous attribuer le dossier.
  • Le ticket disparaît du Pool et rejoint votre liste personnelle ("Mes Tickets en cours").

Exemple d’écran du Pool (File d'attente)

4. Mes Tickets (Dossiers en cours)

Une fois pris en charge, le ticket est sous votre responsabilité. Vous pouvez :

  • Voir les détails complets (Description, PJ, Hostname).
  • Discuter avec l'utilisateur via le Chat Ticket.
  • Clôturer le ticket une fois résolu (bouton vert).

File d'attente des tickets assignés

Detail d’un ticket avec option de clôture

4. Team Chat

Accessible sur la partis droite de l'espace solver, le Team Chat est un espace de discussion réservé uniquement aux membres de votre service (Entre Solver uniquement).
Les autres utilisateurs ne voient pas ces échanges. Utilisez-le pour demander de l'aide à un collègue sur un dossier ou autre.
